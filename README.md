# LunaBot

> ⚠️ **当前版本：v0.5 测试版**
>
> 本项目仍处于早期测试阶段，各项功能适配尚不完善，可能存在Bug和不稳定情况。欢迎提交Issue和PR。

基于 NapCat + DeepSeek API 的 QQ 群 AI 机器人，支持图文视频多模态交互、**分层记忆（人物画像 + 临时记忆 + 向量记忆库）**、语音回复、文生图、主动冒泡、QQ空间说说等功能，配有完整 WebUI 控制面板。

---

## ✨ 已完成功能

### 🎯 核心对话

| 功能 | 说明 |
|---|---|
| **AI 对话回复** | 基于 DeepSeek API，思考强度可调（关闭/低/中/高），群聊@触发 / 私聊直接触发 |
| **图片识别** | 视觉模型看图说话，支持联网搜索，自动缓存图片；**私聊发表情/图片/视频时直接触发回复**（不用再补一句文字） |
| **视频理解** | 自动抽帧 + Whisper 语音转文字，让 AI 能"看懂"群友发的视频 |
| **语音回复 TTS** | 支持火山引擎 / Edge TTS / MiniMax speech-2.8-hd 三引擎切换，MiniMax 支持语气词 |
| **语音转文字 ASR** | 本地语音小模型识别群友语音，转成文字给 AI |
| **自由聊天/插话** | 不需要@也能按概率自动接话，支持回复后连续延续 |
| **消息合并防抖** | 连续消息在窗口内合并成一次回复，保留发送者不张冠李戴；**接入 NapCat 输入状态事件后，对方停止输入 5 秒即提前回复**（不用死等合并窗口） |
| **随机延迟防检测** | 发送前随机等待，模拟真人打字节奏 |
| **回复分段** | 长回复自动拆成多条发送，避免刷屏 |
| **思考链显示** | WebUI 开关：关=只打印字节数，开=打印完整思维链（调试用） |

### 🧠 记忆系统（v2 + 记忆库）

| 层 | 说明 |
|---|---|
| **人物画像** | 每人一份长期档案（上限 3000 字），AI 用 `remember` 工具记录；超过 2000 字后台自动压缩到 1400 字，只压缩不删除 |
| **全局备忘** | 跨用户的公共记忆，与画像同套压缩规则 |
| **临时记忆** | 每个聊天框 15 轮上下文 + 最近 15 条说说 + 10 条临时备忘，实时写盘，重启恢复 |
| **近期摘要** | 打分时顺带生成流水账摘要（`[时间][私聊/群聊：来源] 内容`），存 `temp.json` 并注入上下文，新摘要顶掉旧的（默认 20 行） |
| **用户信息** | 启动从 NapCat 拉取群名片/身份/等级/群名/私聊昵称，每小时刷新，每次对话注入 |
| **记忆库** | 每条消息原文入库 + 0-10 分 + 标签 + 摘要 + 向量；AI 用 `search_memory` 按语义检索（带前后文），解决"上下文刷掉就忘事" |
| **省流模式** | 开关：开=只注入主要人物+给搜索工具；关=全量注入（效果最好，成本高） |
| **自动维护** | 记忆库 3 天评估一次低分记忆（冷存/删除），18000 条自动清理；全量注入过大只提醒一次开省流 |

## 📦 部署

### 架构

```
qq-napcat      ← QQ 协议端（消息收发）
qq-bot         ← AI 主程序（对话/多模态/记忆/下载/主动消息）
qq-controller  ← WebUI 控制面板（localhost:6650）
dtk-api/worker/redis/postgres  ← 抖音独立解析服务
```

### 快速开始

```bash
docker compose up -d
```

WebUI 默认 `http://localhost:6650`，首次启动在 NapCat WebUI 添加反向 WebSocket 地址 `ws://qq-controller:6701`。

> 注意：控制器启动时会把 `webui-dashboard.html` 读进内存，**改完 WebUI 需要重启 controller 容器**（`docker compose restart qq-controller`）再刷新页面。

### 记忆系统相关

- 宿主机 `./memory` 挂载到容器 `/app/memory`，存放：
  - `profiles.json`（人物画像 + 全局备忘）
  - `temp.json`（上下文 / 说说 / 近期摘要 / 备忘 / 最近发言人）
  - `userinfo.json`（从 NapCat 拉取的用户信息缓存）
  - `bank.jsonl` + `bank_emb.bin`（记忆库原文与向量）
  - `compress.log`（压缩日志）、`*.bak`（自动备份）
- 记忆库向量模型：阿里百炼 `qwen3.7-text-embedding`（OpenAI 兼容），需在 `qqbot-config.yml` 填 `embedding_api_key`
- 更换 embedding 模型或维度后必须清空 `bank*` 文件重建
- 成本参考：约 50 次对话/天时，向量 + 打分合计几分钱/天
