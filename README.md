# LunaBot

> ⚠️ **当前版本：v0.5 测试版**
>
> 本项目仍处于早期测试阶段，各项功能适配尚不完善，可能存在Bug和不稳定情况。欢迎提交Issue和PR。

基于 NapCat + DeepSeek API 的 QQ 群 AI 机器人，支持图文视频多模态交互、永久记忆、语音回复、文生图、主动冒泡、QQ空间说说等功能，配有完整 WebUI 控制面板。

---

## ✨ 已完成功能

### 🎯 核心对话

| 功能 | 说明 |
|---|---|
| **AI 对话回复** | 基于 DeepSeek API，思考强度可调（关闭/低/中/高），群聊@触发 / 私聊直接触发 |
| **图片识别** | 视觉模型看图说话，支持联网搜索，自动缓存图片 |
| **视频理解** | 自动抽帧 + Whisper 语音转文字，让 AI 能"看懂"群友发的视频 |
| **语音回复 TTS** | 支持火山引擎 / Edge TTS / MiniMax speech-2.8-hd 三引擎切换，MiniMax 支持语气词 |
| **语音转文字 ASR** | 本地语音小模型识别群友语音，转成文字给 AI |
| **永久记忆系统** | 成员档案（喜好/风格/口头禅）、共享备忘、会话上下文持久化，公开/私密分层 |
| **自由聊天/插话** | 不需要@也能按概率自动接话，支持回复后连续延续 |
| **消息合并防抖** | 连续消息在窗口内合并成一次回复，保留发送者不张冠李戴 |
| **随机延迟防检测** | 发送前随机等待，模拟真人打字节奏 |
| **回复分段** | 长回复自动拆成多条发送，避免刷屏 |

### 🤖 AI 主动行为

| 功能 | 说明 |
|---|---|
| **AI 主动消息** | 长时间没人说话时，AI 自己找话题主动发群/私聊，像真人冒泡；有人说话立刻重置 |
| **QQ空间说说** | AI 可调工具发说说到空间（朋友圈），纯文字，所有人可见 |
| **发说说工具** | 正常聊天时群友说"发条说说"AI 也能调，function calling |
| **主动消息冷却** | 冷却时间可配，连续几次没人回自动放弃该目标，有人说话立刻恢复 |

| GitHub 搜索 | 查开源项目信息 |
| 群成员查询 | 模糊搜群友，返回 QQ号/群名片/身份 |

| 文生图 | MiniMax image-01，支持参考图，比例可选 |

| 记忆工具 | AI 自行更新成员档案/备忘 |

## 📦 部署

### 架构

```
qq-napcat      ← QQ 协议端（消息收发）
qq-bot         ← AI 主程序（对话/多模态/记忆/下载/主动消息）
qq-controller  ← WebUI 控制面板（localhost:6650）
dtk-api/worker/redis/postgres  ← 抖音独立解析服务
```

### 快速开始

```bash
docker compose up -d
```

WebUI 默认 `http://localhost:6650`，首次启动在 NapCat WebUI 添加反向 WebSocket 地址 `ws://qq-controller:6701`。
